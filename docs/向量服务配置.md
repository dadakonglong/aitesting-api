# 向量服务配置说明

出现「未配置向量服务（请设置 QDRANT_URL 与 OPENAI_API_KEY）」时，按下面步骤配置即可启用语义检索（同步到向量库、场景生成时按语义匹配接口）。

## 1. 在项目根目录配置 `.env`

在项目根目录（与 `services`、`frontend` 同级）的 `.env` 文件中增加或确认以下变量。

### 必填

| 变量名 | 说明 | 示例 |
|--------|------|------|
| `QDRANT_URL` | Qdrant 服务地址 | 本地：`http://localhost:6333`<br>云版：`https://xxx.us-east4-0.gcp.cloud.qdrant.io` |
| `OPENAI_API_KEY` | 用于 **向量化（Embedding）** 的 API Key | 目前使用 OpenAI `text-embedding-3-small`，需填写有效的 OpenAI Key |

### 可选

| 变量名 | 说明 |
|--------|------|
| `QDRANT_API_KEY` | 云版 Qdrant 需要；本地部署可省略 |
| `OPENAI_BASE_URL` | 对话模型使用的 API 地址（如 DeepSeek：`https://api.deepseek.com/v1`）。**注意：DeepSeek 不提供 embedding 接口**，若此处填了 DeepSeek，需单独配置下面向量化相关变量。 |
| `EMBEDDING_BASE_URL` | **向量化（Embedding）** 专用 API 地址。若对话用 DeepSeek，此处应设为 `https://api.openai.com/v1`，否则会报「Embedding failed: Connection error」。 |
| `EMBEDDING_MODEL` | 向量化模型名，默认 `text-embedding-3-small`。 |
| `EMBEDDING_API_KEY` | 向量化专用 API Key；不设则使用 `OPENAI_API_KEY`。对话用 DeepSeek、向量用 OpenAI 时可分别配置。 |
| `DEEPSEEK_API_KEY` | 若对话使用 DeepSeek，填写 DeepSeek Key；向量化建议用 `EMBEDDING_BASE_URL` + OpenAI Key。 |

## 2. 配置示例

**本地 Qdrant：**

```env
QDRANT_URL=http://localhost:6333
OPENAI_API_KEY=sk-your-openai-key
```

**对话用 DeepSeek、向量用 OpenAI（推荐，避免 Embedding failed: Connection error）：**

```env
QDRANT_URL=http://localhost:6333
OPENAI_API_KEY=sk-your-openai-key
EMBEDDING_BASE_URL=https://api.openai.com/v1
OPENAI_BASE_URL=https://api.deepseek.com/v1
DEEPSEEK_API_KEY=sk-your-deepseek-key
AI_PROVIDER=deepseek
```

**云版 Qdrant（如 Qdrant Cloud）：**

```env
QDRANT_URL=https://你的实例id.us-east4-0.gcp.cloud.qdrant.io
QDRANT_API_KEY=你的云版 API Key
OPENAI_API_KEY=sk-your-openai-key
```

## 3. 启动方式与 .env 加载

- 推荐在**项目根目录**执行：  
  `python services/ai-processing/main_sqlite.py`  
  或通过 uvicorn 启动时工作目录在项目根。
- 程序会优先从**项目根目录**的 `.env` 加载环境变量，这样无论从哪个子目录启动，都能读到同一份配置。

## 4. 如何确认已生效

- 启动 AI 服务后，若控制台输出：**「向量服务已启用（场景/接口将优先按语义检索）」**，说明配置成功。
- 若报 **「Embedding failed: Connection error」**：
  - 当前对话若使用 DeepSeek（`OPENAI_BASE_URL=https://api.deepseek.com/v1`），DeepSeek 不提供 embedding 接口，需单独配置 **`EMBEDDING_BASE_URL=https://api.openai.com/v1`**，并保证 `OPENAI_API_KEY` 为有效的 OpenAI Key（或设置 `EMBEDDING_API_KEY`）。
  - 若网络需代理，可检查本机代理或防火墙是否拦截对 embedding 接口的访问；向量服务已禁用系统代理（`trust_env=False`），必要时在能直连的环境运行。
- 若仍报「未配置向量服务」或 503：
  - 检查 `QDRANT_URL`、`OPENAI_API_KEY` 是否已写在**项目根**的 `.env` 中且无拼写错误。
  - 云版 Qdrant 需同时配置 `QDRANT_API_KEY`。
  - 确认 Embedding 使用的 API Key 有效且 `EMBEDDING_BASE_URL`（或 `OPENAI_BASE_URL`）指向支持 embedding 的服务。

## 5. 未配置时的行为

不配置或配置失败时，向量服务不会启用，但系统仍可运行：

- 「同步到向量库」接口会返回 503。
- 场景生成时不会使用向量检索，改为**关键词排序**匹配接口，功能降级但可用。
